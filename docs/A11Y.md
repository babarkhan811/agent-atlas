# Accessibility (target: WCAG 2.2 AA)

## Automated (runs in CI on every push)

`tests/e2e/a11y.spec.ts` runs axe-core (WCAG 2.0/2.1/2.2 A + AA rules) on a lesson in Network view, a lesson in Sequence view, the guide, the glossary and the 404 page, each in dark **and** light theme.

**Result at M2 (2026-11-19): 0 serious or critical violations on all 10 page/theme combinations.**

Issues axe found and that were fixed in M2: label-in-name mismatches (logo, layer buttons, diagram nodes, sequence messages), a keyboard-unreachable scrolling code block, and low-contrast text (`--dim`, light-theme accent and kind colours, dimmed "future" trace rows).

## Keyboard pass (automated in `tests/e2e/regressions.spec.ts`, bug 8)

| Check | How it works | Verified |
|---|---|---|
| Skip link | First Tab focuses "Skip to content"; Enter moves focus to the simulation | ✅ test |
| Visible focus | `:focus-visible` outline on every control; focused diagram nodes and sequence messages get a solid highlight | ✅ visual |
| View switcher | `role=tablist`; Arrow keys move between Network/Sequence; `aria-selected` and roving `tabindex` | ✅ test |
| Diagram nodes | Each node is a focusable button named by its visible label; Enter/Space jumps to that node's next message; a description lists messages sent/received | ✅ test |
| Sequence messages | Focusable buttons; Enter/Space selects the step | ✅ manual (keyboard) |
| Timeline | Native range input with `aria-valuetext` "Step 3 of 8: …"; arrow keys move between steps | ✅ test |
| Trace table | Each row has a "Go to step N" button | ✅ |
| Shortcuts | ← / → step, Space play/pause, Ctrl/⌘ K search, Esc closes the drawer. Space and arrows are left alone when a control owns them (bug 1) | ✅ test |
| Theme toggle | `aria-pressed` reflects dark theme | ✅ test |

## Screen reader

**Not yet done with a real screen reader.** This needs a human. Before launch, check with NVDA + Firefox (Windows) and VoiceOver + Safari (macOS/iOS):

1. Landmarks are announced: banner, "Lessons" navigation, "Simulation", "Lesson details", "Message trace".
2. Changing step announces the caption ("Step 03, …") once, via the polite live region.
3. Focusing a diagram node reads its name, kind and message counts.
4. The decoded-message panel reads in a sensible order (route, title, explanation, fields).
5. Search announces "N lessons and M glossary terms match".
